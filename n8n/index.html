O que é preciso para rodar

  1. n8n (nuvem ou servidor próprio).
  2. Conta no WhatsApp Business Platform (Meta), com número verificado e modelos de mensagem aprovados.
  3. Chave da API da Anthropic (Claude), salva como credencial no n8n, nunca no fluxo.
  4. Supabase (ou o banco do sistema da clínica) para agenda e orçamentos; Google Sheets e Gmail para os leads.
